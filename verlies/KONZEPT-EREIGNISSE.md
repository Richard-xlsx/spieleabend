# Ereignisse in unbekannten Räumen

Stand 15.11.2026. Ein Raum „?“ ist zu etwa 22 % ein Hinterhalt und zu 10 % ein Fundstück, sonst ein Ereignis.
Jedes Ereignis kommt pro Ebene höchstens einmal. Bei vielen Ereignissen hilft eine bestimmte Rolle in der Gruppe.

## Für alle

| Ereignis | Wahl | Was passiert | Rolle hilft |
|---|---|---|---|
| Ein alter Brunnen | trinken / nicht | 55 %: +9 Leben, +2 Höchstleben, sonst −4 Leben | |
| Ein schlafender Troll | schleichen / umkehren | Gold, oder alle −6 Leben | Dieb, Waldläufer: 85 % statt 50 % |
| Ein Händler in Kapuze | Trank kaufen / weiter | jeder 1 Trank für 8 Gold | |
| Ein Altar mit Inschrift | 15 Gold opfern / nicht | +5 Höchstleben | |
| Eine wackelige Brücke | tasten / rennen | −3 Leben oder 50 %: −8 | |
| Ein Gefangener im Käfig | befreien / weiter | 55 %: Gold, sonst Hinterhalt (Kampf) | Paladin, Heilerin: 75 % |
| Leuchtende Pilze | essen / liegen lassen | je 50 %: +4 Höchstleben oder −6 Leben | Heilerin, Waldläufer: alle +4 |
| Ein vergessenes Waffenlager | Waffe / Rüstung / nichts | jeder 40 %: +1 Waffe oder +1 Rüstung | Kämpfer, Paladin: 60 % |
| Eine Statue mit Edelsteinaugen | Augen herausbrechen / weiter | 50 %: viel Gold, sonst Kampf | Dieb: sicher Gold |
| Eine verwundete Abenteurerin | Trank geben / ausrauben / weiter | Trank: +1 Talentpunkt für jeden. Ausrauben: Gold, aber Gegner der Ebene +6 % Leben | |
| Eine verschüttete Bibliothek | lesen / einpacken | +18 Erfahrung oder Gold | Magierin, Nekromant: +26 |
| Eine Schale aus dunklem Stein | 6 Leben geben / nicht | Wunden geheilt, alle Fähigkeiten bereit | |
| Ein ruheloser Geist | begraben / weiter | alle heilen ein Viertel | Paladin, Heilerin: zusätzlich +3 Höchstleben |
| Ein Ork mit Wettlust | annehmen / ablehnen | 45 %: +20 Gold, sonst −10 | Kämpfer, Mönch, Paladin: 75 % |

## Einer für alle (die Gruppe stimmt über einen Helden ab)

| Ereignis | Was passiert |
|---|---|
| Ein Fallgitter mit Hebel | Der Gewählte verliert 10 Leben und bekommt 1 Talentpunkt, die anderen teilen sich das Gold. Ab 2 Helden. |
| Ein Runenschwert im Stein | Der Gewählte bekommt +2 Schaden (oder +8 Höchstleben, wenn die Waffe schon am Höchstwert ist), die anderen je 15 Gold. Man kann es auch stecken lassen. |
